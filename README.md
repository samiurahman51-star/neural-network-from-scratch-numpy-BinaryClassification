# neural-network-from-scratch-numpy-BinaryClassification
A neural network built from scratch in NumPy: dense layers, ReLU, Softmax, Sigmoid, categorical and binary cross-entropy, backpropagation, L1/L2 regularization, dropout, and SGD, Adagrad, RMSprop and Adam optimizers. Self-study project based on the book “Neural Networks from Scratch in Python”
